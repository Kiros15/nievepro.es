# NievePro — Vercel

1. Crea un repositorio GitHub, por ejemplo `nievepro-web`.
2. Sube el contenido de esta carpeta a la raíz del repositorio.
3. En Vercel: **Add New → Project → Import Git Repository**.
4. Selecciona el repositorio.
5. Framework Preset: **Other**.
6. Build Command: vacío.
7. Output Directory: `.`.
8. Pulsa **Deploy**.
9. Después: **Project → Settings → Domains → Add Domain**.
10. Añade `nievepro.es` y `www.nievepro.es`.
11. Configura en tu proveedor de dominio exactamente los DNS que te indique Vercel.

La web es estática, mobile-first y preparada como base para SEO, afiliación y AdSense. Los SVG son gráficos locales de demostración; en la siguiente fase podemos sustituirlos por fotografías reales y conectar los productos con afiliación.
